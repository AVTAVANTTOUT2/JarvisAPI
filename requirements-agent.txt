# JARVIS Agent — dépendances minimales pour le client distant
# (script `scripts/jarvis_agent.py` à installer sur les machines secondaires,
# typiquement un MacBook Pro qui se connecte au Mac Mini via Tailscale).
#
# Installation :
#   python3 -m venv venv-agent
#   source venv-agent/bin/activate
#   pip install -r requirements-agent.txt
#
# Lancement :
#   python scripts/jarvis_agent.py \
#     --server https://jarvis.votre-tailnet.ts.net --pairing-code 123456
#
# HTTP est accepté uniquement sur 127.0.0.1/::1/localhost. Pour une PKI privée,
# fournir le certificat CA avec --ca-bundle /chemin/ca.pem ; il n'existe pas de
# mode --insecure afin de protéger jeton, captures et commandes TTS.
